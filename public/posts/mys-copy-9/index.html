“Hello World"与最最基础的语法

以下是一个最最基础的程序

#include <stdio.h>

int main(){
  printf("Hello World!");
  return 0;
}

这个程序相信大家都会写，但或许你还有些不知道的东西

什么是 stdio.h ？

  • stdio是standard的缩写；i，input，表示输入；o，output，表示输出
  • stdio.h 就是：标准输入输出的头文件，提供了我们最常用的printf、scanf函数。毕竟我相信我们都无法手搓一个printf/scanf函数出来
